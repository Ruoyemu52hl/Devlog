## 简介

《火影忍者》是一个横板格斗PVP手游，作为《火影忍者》的**忠实老玩家**（143级），我对它的**决斗场战斗系统**非常感兴趣，所以在本篇报告中，我将尝试从基本规则、对局目标、胜利条件、战斗资源、资源如何带来战斗收益、每个回合的战斗阶段差异、核心战斗循环、资源博弈、资源策略分工、玩家体验等多个维度来进行拆解。

以**决斗场单人模式**的忍术对战玩法为例（**PVP**）。

## 1.基本规则与对局目标

### 1.1 基本规则

开战前准备：

玩家挑选三名忍者和三只通灵以及为每个忍者选择相对应的一个密卷，从左到右进行排序，最左边的忍者最先进入回合战斗，最左边的通灵也优先被使用。调整好**阵容顺序**后，即可开始匹配另一个玩家进行一场对局，**每场对局中有多个回合**，玩家与对方会被随机分配到1p与2p，1p在场景左边，2p在场景右边。

战斗规则描述：

**每个回合1分钟**，每个回合按照忍者顺序依次进行忍者一对一对战，所以每场对局可能有3到5个回合，在本回合内击败对方忍者或是在回合结束时取得血量优势即可获得本回合胜利，反之亦然，取得回合胜利后若对方还有忍者则我方当前忍者进入下一回合与对方的剩余忍者对战。

每个回合开始时，都会**重置对局节奏**以及双方忍者的技能冷却与密卷冷却，上个回合获胜方忍者还会获得一定比例的回血，但是**通灵为一次性资源**，消耗了之后不会恢复，且通灵是非常重要的资源，使用得当可以为我方带来巨大优势。

普遍每个忍者都拥有普通攻击、两个技能、替身以及一个奥义，除了拥有冷却时间外，使用**替身需要消耗一个奥义点**，释放奥义需要消耗四个奥义点，奥义点在对局开始时每方拥有两个，上限四个（普遍），技能命中后会获得一个。

花费四个奥义点击杀对方后可以观看奥义图，并且在下一个回合开始时获得一个奥义点。

被对方成功起手后，忍者会处于**僵直状态**，需要花费替身脱离受击或是等对方连招失误才能继续操控忍者。

处于僵直时不能进行任何操作。（除某些密卷与忍者有特殊机制，僵直时也可释放。）

关于忍者状态：

**硬体：**&#x4F7F;用技能时处于硬体状态，此状态不会被普通攻击打入僵直，但会被技能、密卷、通灵打断，被对方成功打断或者我方释放完技能后退出该状态；

**霸体：**&#x4F7F;用“阴愈伤灭”密卷获取霸体状态，或某些忍者的技能与特殊机制提供霸体状态，在霸体状态下，受到除抓取之外的任何攻击类型都不会进入僵直状态，若被抓取攻击命中，虽会陷入僵直，但不会清除霸体，使用“散”这个密卷可以清除除金刚体之外的任何状态，并让对方陷入短暂僵直。

**金刚体：**&#x91CA;放奥义期间获得此状态，此状态不会被任何攻击打断，直至奥义结束，当玩家释放奥义后，若当前忍者的奥义没有无敌，仍可能会受到伤害，并且释放奥义期间不能进行任何其他操作。

**无敌帧与无敌：**&#x67D0;些忍者的技能与普通攻击夹杂着无敌帧，无敌帧期间无受击框，可以躲避对方的攻击，替身之后拥有一小段的无敌时间，部分忍者释放奥义后也会获得无敌状态，无敌状态不会受到伤害。

### 1.2 对局目标与胜利条件

对局目标：\
不断积累血量、替身、技能冷却等资源以及场面位置上的优势，使对方在关键回合中缺失可用抵制。

胜利条件

玩家在与对方最后一个忍者的回合战斗中取得胜利则视为本局的游戏胜利。

## 2.战斗资源

拥有

| 资源  | 系统作用               | 需要关心的问题                    |
| --- | ------------------ | -------------------------- |
| 血量  | 判断回合胜负             | 这次换血值不值得                   |
| 替身  | 被僵直后的脱离受击          | 奥义点的管理，现在替身能不能取得反手         |
| 技能  | 起手、防身、连招           | 技能应该怎样规划，如果空了下一步要干嘛        |
| 密卷  | 通用补强或者战术补位         | 是用来起手，反制，还是压场等             |
| 通灵  | 强起手、强反手或具有机制的一次性资源 | 是用来抢先手，还是准备打反手，当前局面值不值得使用  |
| 奥义点 | 使用替身与奥义的前提         | 当前的奥义点数量还剩多少，需要使用奥义击杀对方忍者吗 |

替身在决斗场中的关键意义，是让被连招的一方获得脱离受击、重新进入博弈的机会；公开攻略也普遍将其描述为受击时消耗奥义点使用的反连招机制。

举个例子，当我方使用技能或者普通攻击起手到对方后，对方被迫交替身或者承受伤害，一旦对方交替身，那么他的替身将处于冷却状态，我方就会获得更大的优势，因为替身之后将会获得一小段的无敌时间，他的替身交了，直接来反手我方，那么我方就可以等待他的无敌时间过了之后再次替身，拿到反手，此时他的替身在冷却时间，那么此时我方就可以进一步拉大血量差距。

## 3.战斗阶段与核心循环

可以将决斗场分为5个阶段

### 阶段A  中立博弈阶段

此时双方处于相互试探阶段，核心是争夺第一次命中。

博弈点：

双方的横向X轴距离与纵向Y轴错位是否处于一个相对安全的位置；

谁的忍者拥有更快、更远或范围更大的起手技能；

是否需要交出密卷或通灵这种高代价和高收益的资源来尝试获取先手；

谁的忍者技能前摇或者后摇较小，对技能能不能对过；

需要走位诱导对方先交关键技能吗，风险与收益如何，如果走位失败被起手到，又该怎么反手；

是否存在霸体、抓取、无敌、脱手、对空、吸附、格挡、延迟斩、墙角补偿、大范围判定；

谁的技能空了之后风险更高；

谁的忍者被克制，或者有特殊机制，存不存在信息差；

### 阶段B  起手成立阶段

起手是将中立状态转化为优势状态的关键节点。

| 起手类型 | 典型方式           | 设计作用                      |
| ---- | -------------- | ------------------------- |
| 技能起手 | 突进、远程、抓取、扫地、瞬身 | 消耗一定资源获得连招机会              |
| 普攻起手 | 卡位、反跑、近身压制     | 高风险、超高收益、低资源成本、让对方怒火攻心    |
| 秘卷起手 | 控制、霸体、脱手、压场    | 补角色短板、留存技能                |
| 通灵起手 | 大范围判定、压场、追击    | 高代价、高价值抢节奏，若忍者极度依赖先手，可以尝试 |

起手成功后，需要考虑使用了多少资源来起手，对方替身后如何利用现有资源进行反手。

### 阶段C  连招兑现

此阶段的目标不是机械的打满伤害，而是做两个选择：

1.交出所有技能打伤害

2.控制连招节奏，连招的同时不断拉扯与对方的距离，诱导对方替身

连招是把一次命中转化为伤害和资源优势的过程。连招越稳定，越容易强迫对手交替身；但连招越贪，越可能在对方替身后被反打。

需要观察：

普攻衔接是否稳定；

某段普攻或者技能是否可扫地、接浮空、击飞；

是否出现保护机制，比如黄保或者红保，扫地伤害保护与伤害衰减；

哪些连招或行为可以骗替身的同时拉开距离；

哪些连招会因为贪伤害而露出后摇，暴露反打窗口。

### 阶段D  替身与反替身

这是《火影忍者》手游决斗场区别于普通横版格斗的重要层。

替身不是简单的“受击逃生”，而是一个**逆转回合归属的资源**，对方替身之后如果双方距离恰当，可能会直接替身到我方身后进行反打，并且替身后拥有1.5秒的无敌时间。

例如，我方连招对手&#x20;

→ 对手替身&#x20;

→ 对手出现在我方附近/身后，此时对手处于无敌状态

→ 我方必须立即判断：

1.是否露出后摇？&#x20;

2.能不能靠走位扭开对方技能？

3.交通灵？

4.交秘卷？

5.技能反打？

6.直接拉开？

| 选择        | 收益                                       | 风险                                          |
| --------- | ---------------------------------------- | ------------------------------------------- |
| 露出后摇后被打   | 如果己方有替身，那么就可以利用替身后的短暂无敌时间进行反打，直接收获一波节奏   | 容易被对方骗替身，拉开距离后跟你进行二次博弈，或者对方直接使用通灵、秘卷或无敌技能反制 |
| 通灵压制      | 通灵的攻击普遍持续时间较长，且范围很大，对方替身后不及时拉开距离很容易被我方反打 | 消耗高价值资源，且可能对方猜到你的意图，直接拉开距离，那么你这次的通灵将毫无价值    |
| 秘卷保护      | 利用使用密卷时的短暂金刚体抵消对方反打窗口                    | 可能失去后续起手工具                                  |
| 扭开技能、拉开重置 | 保留资源、避免赌博                                | 放弃即时反击机会，需要再进行一次博弈                          |

### 阶段 E  残局与斩杀

残局与前期不同，核心从“建立优势”变成“避免失误”。

重点注意：

1.血量领先方是否能靠走位、诱骗和 CD 优势拖时间；

2.血量落后方是否必须冒险起手；

3.对方无替身时，奥义是否形成确定斩杀；

4.通灵和秘卷在残局是用于补刀，还是用于反手；

5.忍者残血时是否存在高爆发翻盘窗口；

6.一旦失误，在自身没有替身的情况下对方可能会交出所有资源来打伤害以拉回血量差距。
